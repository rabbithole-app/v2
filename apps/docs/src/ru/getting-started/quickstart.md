## Начало работы

1. Перейдите на [rabbithole.app](https://rabbithole.app)
2. Нажмите **Войти** и авторизуйтесь через [Internet Identity](https://id.ai/)
3. **Создайте хранилище** — оплатите фиксированную стоимость, и ваша персональная канистра будет развёрнута на блокчейне примерно за минуту
4. Работайте с файлами:

| Возможности | |
|---|---|
| Загрузка и скачивание файлов | Организация по папкам |
| Переименование, перемещение, удаление | Расшаривание файлов и папок другим пользователям |

Всё шифруется автоматически — вам не нужно об этом думать.

:::tip{title="Хотите узнать больше?"}

Читайте [Как работает шифрование](/ru/how-it-works/encryption), чтобы понять, как защищены ваши файлы, или [Суверенитет данных](/ru/how-it-works/sovereignty), чтобы узнать, почему ваши данные принадлежат только вам.

:::
