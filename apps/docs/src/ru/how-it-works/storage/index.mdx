## Режим хранения и режим шифрования — это разные выборы

Rabbithole задуман вокруг сквозного шифрования и владения персональной
канистрой.

Эти режимы хранения описывают **где хранится файл**.  
Шифрование — это **отдельная настройка**, зависящая от тарифа и конфигурации
папки.

Есть два режима хранения:

- **Blob Storage** для более низкой стоимости и больших файлов
- **On-chain Storage** для более простой модели доверия и максимальной суверенности

:::tip{title="Короткий вывод"}

Если нужен лучший вариант по умолчанию для повседневного использования, выбирайте **Blob Storage**.  
Если хотите, чтобы всё хранилось внутри вашей персональной канистры, выбирайте **On-chain Storage**.

:::

:::details{title="Где выбирается режим хранения"}

При создании хранилища Rabbithole предлагает выбрать **Blob Storage** или
**On-chain Storage** до оплаты. Шифрование остаётся отдельной возможностью:
режим хранения определяет, где лежат байты файла, а режим шифрования определяет,
будут ли эти байты зашифрованы до загрузки.

:::

## Два режима хранения

### Blob Storage <Badge type="tip">Рекомендуется</Badge>

- Около **$0.05 за ГБ в месяц**
- Лучше подходит для больших файлов и более низкой стоимости
- Файл хранится во внешнем object storage
- Ваша персональная канистра хранит правила доступа и данные для проверки файла

### On-chain Storage <Badge type="info">Максимальный контроль</Badge>

- Около **$1.04 за ГБ в месяц**
- Лучше подходит тем, кому нужна максимально простая модель доверия
- Файл хранится прямо в вашей персональной канистре
- Нет зависимости от внешнего слоя хранения

## Сравнение

| | Blob Storage | On-chain Storage |
|---|---|---|
| **Для кого** | Повседневное использование | Максимальная суверенность |
| **Оценочная стоимость** | Около **$0.05/ГБ в месяц** | Около **$1.04/ГБ в месяц** |
| **Где хранится файл** | Во внешнем object storage | В вашей персональной канистре |
| **Что хранит ваша канистра** | Запись о файле, правила доступа, данные проверки | Запись о файле, правила доступа, сам зашифрованный файл |
| **Модель доверия** | IC + локальная проверка + storage-сервис | IC + криптография |

:::note{title="О стоимости"}

Это ориентировочные значения для сравнения. Реальная стоимость хранения может меняться со временем.

:::

:::note{title="Целостность и доступность — не одно и то же"}

Проверка помогает обнаружить незаметную подмену файла.  
Она не гарантирует, что файл будет доступен вечно.

:::

## Что одинаково в обоих режимах

- Ваша персональная канистра остаётся местом, где хранятся права доступа и
  владение файлом.
- Rabbithole строится вокруг зашифрованного хранения, даже если шифрование
  зависит от тарифа и настроек папки.
- Проверка целостности остаётся частью пути хранения.

## Что будет, если Rabbithole исчезнет?

**On-chain Storage:** файл останется в вашей канистре, пока у неё есть
[циклы](/ru/how-it-works/payment).

**Blob Storage:** канистра по-прежнему хранит запись о файле и данные, нужные
для проверки файла. Доступность самого файла дальше зависит от финансирования
хранения и политики retention.

:::note{title="Rabbithole — это интерфейс, а не владелец ваших данных"}

Долговечная система записи — это ваша канистра. Rabbithole — лишь один из способов получить к ней доступ.

:::
