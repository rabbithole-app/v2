features:
  - title: Personal storage
    details: Your storage is a separate Internet Computer canister with its own web interface. After control is transferred, it belongs to you, while Rabbithole remains a service around it, not the owner of your data.
    icon: 🏛️
  - title: Encryption before upload
    details: Rabbithole encrypts the file before it leaves your device. The storage works with encrypted data, not readable file contents.
    icon: 🔐
  - title: Keys on demand
    details: The file key is not sitting ready in storage or at Rabbithole. It is derived through vetKeys at access time and returned encrypted for your browser.
    icon: 🗝️
  - title: Encrypted sharing
    details: You can share a storage, folder, or file while keeping encryption. Rabbithole changes the access rule instead of creating a second file copy.
    icon: 🤝
  - title: Passwordless sign-in
    details: Rabbithole uses Internet Identity for passkeys, biometrics, or supported social login. Rabbithole does not keep a separate password database.
    icon: 🔒
  - title: Verifiable trust model
    details: Rabbithole does not ask you to trust words alone. The code is open, and the docs show how encryption, vetKeys, permissions, and storage ownership work.
    icon: 📖
